Solve real cyber attacks, step by step

Each case drops you onto a compromised machine with a story and a question. Use real Linux commands to follow the trail — and submit what you find at every step.

  • 01Which file extension did the ransomware add?
  • 02Which process is still encrypting files?
  • 03Which file did the user open that started it?
  • …How does it survive a reboot — and who is it talking to?

The first 2 steps of every case are free. 100% simulated — nothing touches a real system.
